# 论文绘图提示词

安装器会把下面的命令和 skill 路径替换为本机实际路径，并生成 `START-HERE.md`。填写方括号中的研究内容后，将正文交给你的 Agent。

---

请根据我提供的材料，为论文绘制一张可编辑、可用于投稿的图片。

**输入材料**
- 论文/方法文件：[填写文件路径或粘贴相关段落]
- 图的类型：[总体框架 / 方法细节 / 数据处理流程 / 概念解释 / 对已有图的修改]
- 本图要传达的核心信息：[一至三句话]
- 必须出现的模块、变量和关系：[填写；没有则从材料提取]
- 参考图或已有源文件：[填写路径；没有写“无”]

**版式要求**
- 图内语言：[英文 / 中文 / 其他]
- 目标尺寸：[单栏 / 双栏 / 宽度与高度；未知则请合理选择并说明]
- 风格：[简洁学术风格；或填写期望的配色与参考]
- 输出文件名：[例如 method_overview]
- 输出格式：可编辑 `.drawio`、PNG、SVG、PDF。

请阅读并使用绘图 skill：`{{SKILL_PATH}}`。先理解材料，列出主要模块与连线含义；材料足够时直接完成绘图。不要捏造研究机制、实验数据或改动公式含义。对于真正影响图意的信息缺口再提问，其余版式细节自行选择。

请用原生 draw.io XML 创建一页图，源文件放 `diagrams/in/`，成品放 `diagrams/out/`。保证每个模块和文字都可以编辑，连线连接到相应模块；图中文字使用 `html=0` 原生文本并禁用 `whiteSpace=wrap` 自动换行，避免 SVG 的 `foreignObject` 导致转 PDF 时丢字。

本机渲染命令前缀为：
```text
{{RENDER_COMMAND}}
```
依次传入输入路径、输出路径、格式、缩放倍率即可，例如 PNG 用 `png 2`，SVG/PDF 用 `svg 1` / `pdf 1`。所有导出通过该包装器执行，PDF 走 SVG → Inkscape（或已配置的 CairoSVG），不直接使用 draw.io 的 PDF 导出。

完成后检查文字是否清晰、是否溢出，箭头方向和连接关系是否正确，字体、线宽、颜色是否一致。打开 PNG 预览并检查 PDF；如果发现问题，修改源 XML 后重新导出。大图先创建长边不超过 1600 像素的预览，原图保持完整分辨率。不要只凭文件存在就宣布图片合格。

最后给出 `.drawio`、PNG、SVG、PDF 的绝对路径链接，简要说明设计与材料是否对应、采用了哪些假设，以及是否存在未验证的导出或字体问题。
